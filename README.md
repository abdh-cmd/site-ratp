# Gestion de transport — RATP

Application web de gestion des affectations de bus : lignes, véhicules, chauffeurs et affectations.

> Projet pédagogique réalisé avec PHP orienté objet et PDO.

## Technologies

- PHP orienté objet
- PDO
- MySQL
- HTML
- Architecture MVC

## Fonctionnalités principales

- Authentification des utilisateurs par session
- Gestion des lignes de transport
- Gestion des bus
- Gestion des chauffeurs
- Création et gestion des affectations
- Ajout, affichage, modification et suppression des données
- Recherche sur les différents modules

## Architecture

- `controleur/` → contrôleurs et logique de l'application
- `modele/` → accès aux données avec PDO
- `vue/` → formulaires et affichage des informations
- `sql/` → script de création de la base de données
- `images/` → icônes et images de l'application
- `index.php` → point d'entrée de l'application
